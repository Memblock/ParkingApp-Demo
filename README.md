# Parking app demo

Ett övningsprojekt i Java som simulerar ett enklare parkeringssystem.

# Bakgrund och syfte

Projektet skapades för att praktiskt utforska grundläggande koncept inom Java, bland annat if/else-satser, logiska operatorer, loopar samt skapande och användning av klasser och objekt.

Istället för att skriva fristående kodexempel ville jag arbeta utifrån ett mer verklighetsnära scenario. Jag bad därför ChatGPT att agera som en fiktiv uppdragsgivare och formulera en kravspecifikation för ett program som skulle använda de koncept jag ville träna på. Resultatet blev detta parkeringssystem.

# AI-Användning

ChatGPT har använts för att skapa det fiktiva uppdraget och dess kravspecifikation. En del av övningen är att själv analysera kraven och implementera lösningen, därför har min instruktion varit att inte få färdig kod eller lösningar på programmeringsproblemen.

På så sätt tränar projektet inte bara programmering, utan även förmågan att läsa och tolka en kravspecifikation, bryta ner ett större problem i mindre delar och stegvis omsätta kraven till fungerande kod.
